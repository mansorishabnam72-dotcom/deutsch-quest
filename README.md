# Deutsch Quest: DTB B2 — نسخه 1.0.0

بازی آموزشی آلمانی با رابط فارسی راست‌به‌چپ، طراحی موبایل‌محور و قابلیت نصب به‌صورت PWA روی Android.

## قابلیت‌ها

- نقشه‌ی ۲۵ مرحله‌ای با بازشدن تدریجی و امکان تکرار مرحله‌ها
- مرحله‌های ۱ تا ۳: واژگان تکمیلی آموزشی مستقل؛ این موارد از کتاب Linie 1 Beruf استخراج نشده‌اند.
- مرحله‌های ۴ تا ۱۴: بانک شامل حدود ۱٬۹۰۰ مدخل کاندید استخراج‌شده از PDF ارسالی در درس‌های ۴ تا ۱۴، همراه با فهرست جست‌وجوپذیر و تمرین چهارگزینه‌ای. استخراج خودکار PDF در برخی سطرها به‌علت ستون‌بندی و ترتیب متن ممکن است معنی را اشتباه جفت کند؛ بانک هنوز ممیزی کامل انسانی نشده و نباید کامل/بی‌خطا تلقی شود.
- مرحله‌های ۱۵ تا ۲۴: تمرین گرامر شامل Dativ/Akkusativ، افعال با حرف اضافه، Wechselpräpositionen، افعال جداشدنی، Konjunktiv II، Passiv، Nebensätze، Infinitiv mit zu، ohne ... zu / ohne dass، sodass و indem.
- مرحله‌ی ۲۵: غول نهایی با تمرین ترکیبی.
- ساخت جمله، Speaking تایپی، پخش نمونه با گفتار مرورگر، و تشخیص گفتار اختیاری در مرورگرهای پشتیبان
- XP، سکه، Combo، قلب‌های هر دور، نشان‌ها، ذخیره‌ی محلی، مرور اشتباه‌ها، و خروجی/بازیابی فایل پشتیبان
- Service Worker برای کش فایل‌های اصلی و اجرای آفلاین پس از اولین بارگذاری موفق

## وضعیت محتوای منبع

PDF ارسالی شامل واژگان درس‌های ۴ تا ۱۴ است. در استخراج فعلی، متن درس‌های ۱ تا ۳ یافت نشد؛ بنابراین آن‌ها به‌عنوان محتوای کتاب جعل نشده‌اند و فقط تمرین تکمیلی مستقل دارند. فایل `data/vocabulary-source.json` هر مدخل را به‌عنوان نامزد استخراج‌شده نگه می‌دارد. برای تضمین «بدون حذف و بدون خطا»، باید هر مدخل و ترجمه در مقابل PDF بازبینی شود؛ نسخه‌ی فعلی چنین تضمینی نمی‌دهد.

## اجرا روی رایانه

از پوشه‌ی پروژه اجرا کن:

```bash
python -m http.server 8000
```

سپس در مرورگر برو به `http://localhost:8000`.

## انتشار و نصب روی Android

1. محتوای پوشه‌ی `deutsch-quest` را در یک مخزن GitHub بارگذاری کن.
2. از تنظیمات مخزن، بخش **Pages** را فعال کن و شاخه/پوشه‌ی منتشرشونده را انتخاب کن.
3. بعد از انتشار، سایت را با HTTPS در Chrome اندروید باز کن.
4. از منوی Chrome گزینه‌ی **Install app** یا **Add to Home screen** را بزن.
5. یک بار اپ را در حالی که اینترنت دارد باز کن تا فایل‌های اصلی کش شوند؛ بعد از آن، بسیاری از بخش‌ها آفلاین در دسترس‌اند.

## Speaking و محدودیت‌ها

- پخش نمونه به پشتیبانی گفتار مرورگر وابسته است.
- Web Speech Recognition در همه‌ی مرورگرها/دستگاه‌ها کار نمی‌کند و معمولاً به HTTPS و اجازه‌ی میکروفون نیاز دارد. در صورت نبود پشتیبانی، پاسخ تایپی در دسترس است.
- ارزیابی Speaking یک بازخورد ساده‌ی تمرینی است، نه ارزیابی رسمی DTB B2 و نه تحلیل دقیق دستور زبان/تلفظ.

## ذخیره‌سازی و حریم داده

پیشرفت در IndexedDB و در صورت لزوم localStorage همان مرورگر ذخیره می‌شود. همگام‌سازی ابری وجود ندارد؛ پاک‌کردن داده‌های مرورگر ممکن است پیشرفت را حذف کند. از بخش پروفایل خروجی JSON بگیر و آن را در جای امن نگه‌دار.

## کنترل‌های فنی انجام‌شده

- بررسی نحو JavaScript با Node.js
- بررسی اعتبار JSON و سلامت ZIP
- آزمون واقعی روی گوشی اندروید و آزمون بین مرورگرها هنوز انجام نشده است.
